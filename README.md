# clipping-pipeline

Experiments and tooling for a short-form clipping side income (Whop Content Rewards campaigns, with GTA 6 as the first big target).

- `AGENT.md`: goal, research findings, active campaigns, experiments and decision gate
- `CLAUDE.md`: Claude Code entry point (imports `AGENT.md`)
- `docs/pipeline-plan.md`: pipeline design and milestones
- `data/clipping-tracker.csv`: per-clip experiment log

Status: experiment phase. Pipeline code starts at milestone M1 once the Call of Duty campaign brief is captured.
